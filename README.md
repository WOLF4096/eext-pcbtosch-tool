# 狼黑工具 · PCB 转原理图

> 手上只有一块板子的图，没有原理图？这个工具帮你把它补回来。

一个嘉立创EDA（专业版）的扩展。它把 PCB 上的元件搬到原理图里：自动分组、自动摆位置、自动配上符号，每个引脚旁边写上它在板子上连的网络名。也可以反过来用——只给已经画好的原理图补上缺的连线。

**适合这些时候用**

- 接手别人的板子，只有 PCB 文件，要出一份能改的原理图
- 维修、仿制，需要对照实际连接
- 老项目图纸丢了，想照着板子重建

工具只在你自己的电脑上运行，读取的都是本地工程，不联网、不上传。

---

## 一、安装

1. 下载扩展文件 `eext-pcbtosch-tool_v1.4.0.eext`（在本项目的 Releases 里拿最新版）。
2. 打开嘉立创EDA 专业版，找到**扩展管理器**（一般在顶部菜单的「扩展」里；不同小版本位置略有差别）。
3. 点「导入扩展」，选择刚下载的那个 `.eext` 文件。
4. 装好后**重开一次客户端**，菜单才会出现。

装好之后，切到原理图界面，顶部菜单会多出一项「**PCB转原理图**」。

**版本要求**：编辑器 2.2.45 及以上，2.x / 3.x / 4.x 都可以用。版本太老会提示「建议更新EDA」。

---

## 二、用之前先准备好这三件事

| 要准备什么 | 为什么 | 怎么做 |
| --- | --- | --- |
| 原理图和 PCB 是**同一个工程里的一对** | 工具要靠这个对应关系知道该读哪块板子 | 正常在工程里建的原理图 + PCB 就已经是配对的 |
| 一个**空白**的原理图页 | 工具是整页重画，不是往上叠加；页面上原有东西会打架 | 右键原理图名 → 新建图页（你的版本里也可能叫「新建图页 / 添加图页」），然后切到这一页 |
| 每个元件都有**符号** | 没有符号就没有图形可以放 | 在 EDA 里给器件做「器件标准化」，或等下在工具里手动指定 |

## 三、把 PCB 变成原理图

### 第 1 步：打开工具

菜单 **原理图 → PCB转原理图 → 从PCB转原理图**，弹出一个小窗口。

### 第 2 步：点「加载数据」

工具会读一遍当前工程，把板子上的元件列成一张表。等状态栏出现「元件处理完成」就好了。

表格一共六列，主要看第四、五列：

| 列 | 看什么 |
| --- | --- |
| 位号 / 名称 / 封装 / 器件 | 元件信息。同一种元件会合并成一行，一行里可能有好几个位号，这是正常的 |
| **匹配符号** | **有内容＝可以直接转；空着＝这个元件还没绑定符号** |
| 指定符号 | 匹配符号空着时，在这里手填符号名（支持直接写 `电阻`、`无极电容`、`电感`） |

### 第 3 步：选排布方式

| 选项 | 效果 | 什么时候选 |
| --- | --- | --- |
| 按位号 | 按 R1、C1、U1 这种编号排队 | 默认，最规整 |
| 按器件 | 同型号的元件排在一起 | 想按功能块看 |
| 按封装 | 同封装排在一起 | 想核对封装 |
| 按元件坐标 | 大致还原元件在板子上的位置 | 想对着实物/PCB 逐块核对 |

下面四个勾选项：

- **显示分类标题**：每组上方写一行组名，并按组画框。（默认已勾）
- **尝试生成导线**：给每个有网络的引脚拉出一小段线，线上带着网名。**建议保持勾选**，这是这个工具最省事的地方。（默认已勾）
- **启用 Y 值翻转**：默认已经按你的 EDA 版本自动设好了。只有当你看到符号整页上下颠倒时才需要动它。
- **忽略符号错误**：勾上则跳过没有符号的元件继续生成；不勾则一旦有元件缺符号就整页不做，并把那几行标红。（默认不勾）

### 第 4 步：构建源码

点「**构建源码**」。这一步只是在后台把图纸内容算出来，**不会动你的画布**，所以可以反复试、反复调选项，直到满意为止。

状态栏会告诉你生成了多少行。

### 第 5 步：选一个出口

| 按钮 | 得到什么 | 说明 |
| --- | --- | --- |
| **写入文档** | 直接画到当前原理图页 | 只认原理图页，切到别的页面会拒绝写入；页面上原来有东西会导致画不出来 |
| **导出文件** | 一份新的工程包 | 原工程不动。元件特别多的板子走这条路更稳，不会卡死客户端 |
| **导出表格** | 一份 CSV 清单 | 就是你在界面上看到的这张表（含手填的符号），方便留档、核对 |
| **导出网络** | 一份 CSV 网络清单 | 唯一ID、位号、引脚编号、引脚名称、引脚网络。要先「构建源码」才能导 |

**建议**：第一次拿大板子试，先「导出文件」，确认结果没问题，再决定要不要直接写入。

## 四、只补导线（原理图已经画好了）

如果原理图是你自己画的，只是懒得一根根连线，用「创建导线」。

菜单 **原理图 → PCB转原理图 → 创建导线**，下面有五个入口：

| 入口 | 做什么 | 什么时候用 |
| --- | --- | --- |
| 来自PCB | 选中元件，照着板子的实际连接补线 | 板子在手边、就开着 |
| 来自网表 | 按已经存好的网表补线，不用切来切去 | 经常补线，或板子不方便开着 |
| 从PCB更新网表缓存 | 把整块板的连接关系存下来 | 想「先存后用」的第一步 |
| 从文件更新网表缓存 | 从网表文件存进来 | 手上有导出的网表文件 |
| 清空网表缓存 | 删掉存着的那份 | 换板子了，怕用错 |

**用法一：直接补**

1. 在原理图里**选中**要补线的元件（可以一次选多个）。
2. 点「来自PCB」。
3. 工具会自动切到 PCB 读一遍、再切回来，只补**还缺的**那些线——已经连好的不会重复画。
4. 完成后底部日志会写：补了多少个引脚、花了多久。

**用法二：先存后用**

1. 点「从PCB更新网表缓存」，提示会告诉你存下了多少器件、多少引脚、多少网络。
2. 以后随时点「来自网表」补线，不需要 PCB 在旁边。
3. 缓存只保留最新的一份，提示和日志里会写明它是从哪来的、什么时候存的。

> 「来自PCB」和「从PCB更新网表缓存」要求原理图和 PCB 在**同一个窗口**里。分屏或开两个窗口时找不到 PCB，会中止并提示你。

## 五、常见问题

**Q：装好了，但菜单里找不到？**
重开客户端。还找不到，就在扩展管理器里确认插件是「已启用」状态，并检查编辑器的版本是否低于 2.2.45。

**Q：点「加载数据」提示找不到对应的原理图？**
当前这张原理图还没和 PCB 关联上。回到工程里把这一对绑定好，或者换到已经绑定的原理图页。

**Q：构建时提示「部分元件没有符号」？**
这些元件在 EDA 里没做器件标准化。两个办法：在表格「指定符号」列手填（`电阻` / `无极电容` / `电感`，或符号的准确名称），或者勾上「忽略符号错误」跳过它们。

**Q：提示写入成功，但画布上什么都没有？**
当前原理图页上有旧内容，新旧图形冲突了。新建一个空白页，重新打开工具再写入。这也是为什么建议先准备空白页。

**Q：写入直接被拒？**
你现在不在原理图页上（可能切到了 PCB 或封装页）。切回原理图页再点写入。

**Q：生成的符号整页上下颠倒，导线跑到符号外面？**
把「启用 Y 值翻转」反过来勾一次，再重新构建。

**Q：元件好几千，点写入就卡死？**
别直接写入。用「导出文件」，再通过「文件 → 打开 → 嘉立创EDA」导入那份新工程包。

**Q：导出文件打开后，只有第 1 页变了？**
导出固定写的是原理图的第 1 页。要改别的页，就在那个原理图的第 1 页上操作，或者改用「写入文档」。

**Q：点「来自PCB」说没选中器件？**
先在原理图里选中元件，再点菜单。

**Q：点「来自PCB」拿不到板子的数据？**
原理图和 PCB 被分屏或开在不同窗口了。关掉分屏、在同一窗口打开两者；或者改用「来自网表」。

**Q：点「来自网表」说缓存是空的？**
还没存过。先点「从PCB更新网表缓存」或「从文件更新网表缓存」。

**Q：更新缓存时提示没取到网表？**
PCB 还没保存，或者刚切过去还没加载完。保存 PCB 后再点一次。

**Q：一行里有好几个位号，是合并错了吗？**
没错。封装和器件都相同的元件会合并显示，实际转换时每个位号各放一个符号。

**Q：转出来的原理图和 PCB 还能联动吗？**
能。元件身份信息一并带过去了，之后用 EDA 自带的「从 PCB 导入变更」还能补全位号、名称和自定义参数。

**Q：会改坏我的工程吗？**
「构建源码」不改。「写入文档」会改当前原理图页（所以请用空白页）；「导出文件」只生成一个新文件，原工程不动。**无论哪种，动手前先备份工程**。
